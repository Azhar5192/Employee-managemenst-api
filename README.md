RESTful Employee Management API built with Node.js, Express.js, MongoDB, and Mongoose.
# Employee Management API

A RESTful API for managing employee records.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript

## Features

- Create employee
- Get all employees
- Get employee by ID
- Search employees
- Filter employees by salary
- Update employee
- Delete employee
- Request validation
- MongoDB persistence

## Run locally

npm install
node server.js
